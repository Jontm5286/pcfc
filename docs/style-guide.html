Animaciones

Transiciones medidas

200ms para UI micro, 800–1200ms para text reveals. Nunca transition: all. Respeta prefers-reduced-motion.

Pasa el cursor aquí
background-color 200ms
Borde animado
border-color 200ms
Cambio de color
color 200ms
Hover →
transform: translateX 200ms

Reglas

  • UI micro (hover, tab change): 150–200ms, ease
  • Entry (sección al scroll): 600–900ms, ease-out
  • Text reveal: 800–1200ms, con stagger 0.03s
  • NUNCA transition: all — especificar propiedades exactas
  • NUNCA rebote/elastic en UI
  • NUNCA transform: scale() en hover de cards
  • SIEMPRE prefers-reduced-motion: reduce → desactivar todo
12
Layout · Capas

Sistema de superficies

Tres capas: fondo base (blanco o navy), contenedores (white/navy con borde 10%) y superficies oscuras (navy + dark). Whitespace generoso entre cards, nunca líneas gruesas.

Capa 0 · Fondo base blanco

Usado en secciones de contenido: categorías, club, inscripción. Texto navy sobre blanco: contraste 14.6:1.

Capa 1 · Contenedor (white #FAFAF9)

Borde navy 10%, border-radius 8px (cards) o 12px (contenedores grandes). Sin sombras estáticas. Whitespace ≥ 2rem entre cards.

Capa 2 · Superficie navy

Fondos hero, CTA, headers. Bordes blancos 8% opacidad. Texto blanco #FAFAF9.

Capa 2 · Superficie navy oscuro

Solo para el footer. Background #071D3B. Bordes blancos 8%.

Reglas de separación

Situación Método
Misma capa (dos cards) Whitespace generoso (gap ≥ 2rem)
Capas diferentes (navy → blanco) Borde fino rgba(0,40,92,0.10) O cambio de fondo
Elevación hover Sombra: 0 4px 20px rgba(0,40,92,0.08)
NUNCA Líneas gruesas (>2px), sombras como separadores, divisores de color fuerte

Container-x · Section padding

container-x: max-width 1280px, padding horizontal clamp(1.25rem, 4vw, 2.5rem).
section: padding vertical clamp(4rem, 8vw, 6rem).

14
Prohibiciones

Lo que NO se hace

PFCF no es una app gaming, ni un startup SaaS, ni una tienda. Estos patrones rompen la identidad del club.

Estilo — NUNCA

Glassmorphism
Card con blur

No usar backdrop-filter: blur() como elemento decorativo. Rompe la sobriedad del club.

Hover scale
Card que crece

Nunca transform: scale(1.05) en hover. Usar cambio de borde + sombra sutil.

Neon / Glow
Brillo magenta

Sin gradientes tipo neón, sin box-shadow: 0 0 30px, sin border-glow. No somos gaming.

Gradiente diagonal
Fondo multicolor

Sin gradientes diagonales como fondo de sección. Solo navy → sky vertical o sólido.

Fondo saturado
Pink saturado

No usar pink, emerald, violet, orange, yellow como fondo. Solo paleta navy + sky.

Grays de Tailwind
gray-100 / gray-600

No usar gray-50, gray-100, gray-200. Usar la escala navy de la marca.

Layout — NUNCA

  • Filas de 3 cards idénticas alineadas al mismo tamaño
  • Alternancia texto/imagen/texto/imagen genérica
  • Hero centrado con título + 2 botones + mockup flotante
  • Grid de 4-6 iconos circulares con título y párrafo debajo
  • Carrusel de testimonios con estrellas de valoración
  • Secciones de "Nuestros servicios" con iconos genéricos

Copy — NUNCA

  • Headlines genéricos: "Nuestros servicios", "Lo que ofrecemos", "Contáctanos"
  • Subtítulos de relleno que no dicen nada
  • CTAs sin contexto: "Haz clic aquí", "Leer más", "Ver todo"
  • Mezclar inglés y español innecesariamente
